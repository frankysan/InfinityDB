An open-source community reference for Infinity

Know your options.

InfinityDB connects official Infinity Army data with maintained N5.3 rules context so you can move between armies, profiles, equipment, weapons, Skills, Traits, States, and the rules that relate them without having to reconstruct those connections yourself.

01

Explore the game data you already use

Browse units by army, profile, availability, Skill, Equipment, and Weapon. Unit pages bring together profiles, loadouts, AVA, characteristics, and army-specific context, while the dedicated catalogs let you approach the same data from the rules or equipment side.

02

Follow rules instead of hunting for them

Skills, Equipment, Traits, and States include concise reviewed summaries, authoritative source links, structured classifications, and bidirectional related-rule links where the interaction can be represented accurately. The goal is not to replace the rules, but to make the relationships around the data easier to understand.

03

Keep source and interpretation visible

InfinityDB imports, normalizes, validates, and reconciles its maintained sources before publishing a read-only application database. Source-native facts, curated rules context, and InfinityDB-specific interpretations are kept distinct so useful presentation does not erase provenance or uncertainty.

Where the project is going

From reference data to a connected Infinity reference.

Version 0.7 focuses on rules context for the catalogs InfinityDB already exposes. The next phase will identify and connect more of the game's structure, including relationships such as Fireteams, Peripherals and Controllers, loadout dependencies, and Reinforcement parentage. Later work will close remaining presentation gaps and improve search, navigation, mobile use, accessibility, and themes on the way to a player-data-complete 1.0 reference.

How InfinityDB is built

Three principles

Accuracy

InfinityDB uses maintained primary sources and aims to preserve what they actually say. When sources are incomplete, version-specific, or ambiguous, that uncertainty should remain visible rather than being silently guessed away.

Connectivity

Useful facts should link to the other facts that give them context. InfinityDB prefers explicit, reviewed relationships over name matching or duplicated prose, while avoiding links that would imply more than the rules support.
